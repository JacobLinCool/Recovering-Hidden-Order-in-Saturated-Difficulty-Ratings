# Dan-i Dojo course snapshot

This directory records factual course placements from the public Taiko Wiki API. The site is a community-maintained transcription of official game content; it is not a Bandai Namco data release. `dojo_source_manifest.json` pins response hashes, API URLs, the website source-code commit/license, and official annual notices used to corroborate the curriculum context.

This release includes the matched maximum-rating placements and the frozen aggregate course-placement results. It contains no player or account data.
