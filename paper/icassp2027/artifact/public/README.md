# ICASSP 2027 public evidence

This directory contains chart-level out-of-fold scores, complete aggregate model results, configurations, sequence-fold run status, and the independent Dan-i Dojo curriculum criterion used by the paper. `chart_key` is a deterministic pseudonym; direct chart titles, chart files, audio, proprietary assets, and gameplay records are excluded. The keys do not promise irreversible anonymity.

`dojo_public_matches.jsonl` contains the 47 official-10 Oni placements for each of two frozen indices. It preserves edition, expert tier, course position, source URL, and model score while omitting chart titles. These public course facts can be reconciled with their public source tables. `dojo_source_manifest.json` records retrieval time, public endpoints, official notices, and hashes of the original private snapshots. The source code is MIT-licensed; no license is asserted for the underlying factual course metadata.

Above-ceiling outputs are relative ordinal indices, not calibrated star units. Course placement was designed independently of the models; the primary panel conditions on the official maximum rating. It is not psychophysical ground truth or a causal player outcome.

`MANIFEST.json` gives hashes and sizes for this release. `reproducibility_inventory.json` is the historical source snapshot, including references to restricted, title-bearing experiment inputs; those inputs are intentionally absent from this public repository. See `REPRODUCE.md` for the exact public verification boundary.
