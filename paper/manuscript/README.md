# Manuscript

Build the paper from this directory with `latexmk -pdf -interaction=nonstopmode -halt-on-error main.tex`. `PORTAL_ABSTRACT.txt` contains the plain-text abstract for the submission form. The source uses `references.bib`, `spconf.sty`, `IEEEbib.bst`, `figures/hidden_order_protocol.tex`, and the checked-in `generated/` TeX and PDF exhibits. The latter are frozen outputs of the study analyses, not hand-entered numbers.

The public evidence package and its verification boundary are described in `artifact/public/README.md` and `artifact/public/REPRODUCE.md`.
